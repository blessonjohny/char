# Greenfield Market

Static grocery storefront. No build step.

## Structure

```
greenfield-market/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

## Publish on GitHub Pages

1. Push these files to the root of your repo.
2. Repo Settings, Pages, Source: "Deploy from a branch", Branch: `main`, folder: `/ (root)`.
3. Your site appears at `https://<username>.github.io/<repo>/`.

Replace the [bracketed] placeholders in `index.html` and `js/app.js` with real details.
